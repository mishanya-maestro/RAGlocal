## Web UI (Flask)

Установить Flask:

```bash
pip install flask
```

Запуск сайта:

```bash
py -3 src/flask_app.py
```

Открыть в браузере:

```text
http://127.0.0.1:5000
```

В интерфейсе доступны 2 вкладки:

- `Обычный` — ответ через RAG (поиск + контекст статей)
- `Сравнение` — одновременно два ответа:
  - с RAG
  - от той же LLM без RAG-контекста

### 🎙️ Голосовой ввод (STT)

В композере рядом с дропдаунами есть кнопка микрофона: первое нажатие
начинает запись, второе — останавливает и отправляет аудио в AssemblyAI
для распознавания. Распознанный текст подставляется в поле ввода — отправляйте
обычной кнопкой или `Enter`.

Добавьте ключ AssemblyAI в `.env`:

```text
ASSEMBLYAI_API_KEY=ваш_ключ
```

Голосовая запись работает только по `localhost` или по HTTPS (требование
браузера для `getUserMedia`).
